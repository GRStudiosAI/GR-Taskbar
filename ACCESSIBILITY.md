# GR Taskbar Accessibility Statement

## Our Commitment

GR Studios AI LLC aims to make GR Taskbar accessible
to users with different abilities and requirements.

## Accessibility Development Goals

- Keyboard navigation.
- Screen reader compatibility.
- Accessible GR Settings controls.
- High contrast compatibility.
- Windows display scaling and DPI support.
- Readable text and interface labels.
- Clear visual focus indicators.
- Customizable Start button artwork.
- Customizable mouse cursors.
- Accessible installation and configuration.

## Supported Environments

Accessibility compatibility depends on the Windows
version, system configuration, assistive technology,
and GR Taskbar version.

## Known Limitations

Some legacy Windows interface components may have
accessibility limitations.

The project does not currently claim full compliance
with any specific accessibility standard.

## Reporting Accessibility Issues

Report accessibility problems through:

https://github.com/GRStudiosAI/GR-Taskbar/issues

Include the affected component, Windows version,
GR Taskbar version, assistive technology, and a
description of the accessibility barrier.

## Continuous Improvement

Accessibility improvements will be considered throughout
the development and maintenance of GR Taskbar.

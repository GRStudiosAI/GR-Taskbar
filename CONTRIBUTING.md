# Contributing to GR Taskbar

GR Taskbar is maintained by GR Studios AI LLC.

## Contribution Guidelines

Contributions should improve stability, performance,
accessibility, customization, or compatibility.

## Development Requirements

- Use the master branch as the development baseline.
- Create a separate branch for proposed changes.
- Preserve GR Taskbar branding and existing functionality.
- Follow existing source code conventions.
- Preserve applicable copyright and attribution notices.
- Comply with the GNU General Public License version 2.
- Do not include credentials or private information.
- Do not include unnecessary compiled binaries.
- Protect native Windows files and components.

## Testing

Test applicable changes for:

- Installation and uninstallation.
- Upgrades and repairs.
- Taskbar and Start menu functionality.
- GR Settings functionality.
- Windows compatibility.
- Performance and stability.
- Accessibility.
- Preservation of user settings.

## Pull Requests

Provide a clear description of the changes,
testing results, affected components, and known limitations.

All contributions are subject to maintainer review.

## License

Contributions must be compatible with the project's
